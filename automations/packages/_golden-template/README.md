# Golden Automation Package v0.1 Template

Copy this directory only when creating a candidate package. Replace the identity, ownership, contract, workflow, evaluation, operational, and provenance metadata with real reviewed values. Never copy a secret value into any package file.

`automation.json` is the release manifest. It points to every required contract and operating document. The package is structurally complete only after the catalogue validator has calculated and verified the workflow and package digests.
