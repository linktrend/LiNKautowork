# SPDX expression validator attribution

The package-local validator is an ESM adaptation of these exact LiNKlibraries
lockfile versions:

- `spdx-expression-validate` 2.0.0 — MIT, Kyle E. Mitchell,
  https://github.com/kemitchell/spdx-expression-validate.js
- `spdx-expression-parse` 3.0.1 — MIT, Kyle E. Mitchell and the authors listed
  by the package, https://github.com/jslicense/spdx-expression-parse.js
- `spdx-license-ids` 3.0.23 — CC0-1.0, SPDX license identifier data,
  https://github.com/jslicense/spdx-license-ids
- `spdx-exceptions` 2.5.0 — CC-BY-3.0, SPDX exception data,
  https://github.com/jslicense/spdx-exceptions

The three JSON files in this directory are the corresponding package data
files from those versions. The SPDX standard and its license/exception lists
are maintained by the Linux Foundation and contributors. The original package
license and attribution notices remain applicable to this adapted copy.
