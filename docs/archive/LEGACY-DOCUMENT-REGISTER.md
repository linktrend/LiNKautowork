# Legacy document register

Effective 2026-09-04, the production PRD and production work packets in the parent `docs` directory are the current planning authority.

The following material is retained as historical evidence but is superseded for future execution unless the current PRD links to it explicitly:

- dated handoffs, transient agent prompts, worker reports, and review snapshots;
- completed implementation plans and packet candidates;
- pre-2026-09-04 readiness, migration, release, or rollout plans;
- IDE consumer-repair plans copied into this repository;
- obsolete provider experiments, temporary HOLD analyses, and superseded branch/PR instructions.

Historical documents must not override current protected code, current contracts, the production PRD, or the production work packets. They remain evidence only and must not be used as live configuration instructions without revalidation.
