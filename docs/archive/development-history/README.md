# Archived development history

These files are retained so agents and maintainers can trace earlier planning,
build decisions, test records, and handoffs. They have been moved here from
active documentation paths as part of LiNKautowork 1.0 consolidation.

- `end-to-end-delivery/` — old delivery plans, planning manifests, and
  readiness documents. The separate source-release receipt folder remains at
  `docs/end-to-end-delivery/evidence/source-release/`.
- `handoffs/` — completed and dated agent session notes.
- `agent-sessions/completed/` — completed session coordination records.
- `planning/` — completed provider/consumer planning and hold analysis.
- `production-roadmap/` — historical roadmap, work packets, and development
  evidence. It is not proof of current production acceptance.
- `OPEN-ISSUES.md` — append-only historical build and compliance log.

For current instructions, use `docs/LINKAUTOWORK-AI-AGENT-GUIDE.md`,
`docs/LINKAUTOWORK-RELEASE-STATUS.md`, current contracts, and runbooks.
Historical paths and claims in this archive should be read in the context of
their original date and commit.
